Applied CATIA to mechanical component design and machining simulation, focusing on milling and turning operations to support manufacturing process planning and validate component geometry.
This project demonstrates my practical experience using CATIA V5 for mechanical component design, machining simulation, and CNC programming. It covers the design of mechanical elements, the simulation of milling and turning operations, and the generation of CNC machining code to support manufacturing.

Project Documentation

The documentation is organized into three files:

Mechanical Component Design (.CATPart)
Contains the 3D CAD model of the mechanical component designed in CATIA. The file illustrates the use of part-design tools to create and define the geometry of the component.

Milling and Turning Simulation
Presents the machining simulations performed in CATIA, demonstrating the milling and turning processes, tool movements, machining sequences, and material removal during manufacturing.

CNC Machining Program (.NC / .TXT)
Contains the CNC program used to control the milling and turning operations. The code defines machining instructions, tool movements, and relevant operating commands for CNC machine execution, depending on the machine configuration and controller.

Skills Demonstrated

3D mechanical modeling and CAD design using CATIA.

Simulation of milling and turning operations.

Understanding of machining strategies and manufacturing processes.

CNC programming fundamentals and G-code interpretation.

Integration of mechanical design with computer-aided manufacturing (CAD/CAM).

This project strengthened my understanding of the relationship between mechanical design, machining simulation, and computer-aided manufacturing, providing practical insight into the transition from a digital component model to a manufacturing program
